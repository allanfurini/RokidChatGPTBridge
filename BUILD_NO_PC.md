# Compilar usando apenas o celular

O projeto inclui GitHub Actions. Você NÃO precisa de Android Studio.

1. Crie um repositório vazio no GitHub.
2. Envie o conteúdo deste ZIP para a raiz do repositório.
3. Abra a aba Actions.
4. Abra "Build APK".
5. Toque em "Run workflow".
6. Quando terminar, baixe o artefato "RokidChatGPTBridge-debug".

O APK dentro do artefato é o que deve ser instalado no CELULAR.

O Rokid Nexus cuida da interface dos óculos; este projeto não instala um segundo APK diretamente nos óculos.
